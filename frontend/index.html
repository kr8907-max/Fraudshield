          HELP

          Using the scanner

          01

          Enter a URL

          Paste any http(s) link. Faulty input is rejected client-side and by the API before any network activity.

          02

          Layered inspection

          The backend scores the URL string, then inspects the live site: DNS, TLS, redirects, read-only content analysis.

          03

          Read the evidence

          Every verdict ships with findings and evidence lines. Overrides of the raw ML score are always explained.

          Check the destination, not the motto

          Look-alike subdomains (e.g. paypal.com.evil.xyz) are not the real brand — the evidence panel shows the final URL of every hop.

          INSUFFICIENT EVIDENCE is cautious design

          Unreachable, blocked, or thin pages never become verdicts. Treat UNVERIFIED as “no claim made”, not as “safe”.

          Raw ML score ≠ final verdict

          The R2 score is a signal, not calibrated probability. A fully verified benign site can override a flagged score — with the reason printed in Evidence.

          This is a research scanner

          No JavaScript is executed and no forms are submitted, so some attacks can't be seen. It complements — never replaces — browser sandboxing and judgment.
